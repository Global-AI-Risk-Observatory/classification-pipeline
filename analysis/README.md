# Analyses

Analyses on the exported runs of the pipeline, outside the classifier. Each analysis is a folder with its script, a README and its results.

- `functional_fragmentation/`: the method of Evalet (Kim et al., CHI 2026) as a script over the evidence quotes of a run; example on MIT subdomain 1.1 from `us-2025h1_V3`, and the research plan's questions 1.1 to 1.4 (`--question`).
- `human_validation/`: the human annotation protocol of the research plan as a script: stratified sample, one Google Sheet per rater, ratings back as coder files, kappa per field.
